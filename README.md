# FinTrack Mac — SwiftUI личные финансы

> **В разработке.** Первая сборка ещё не прошла полноценную проверку на macOS. Не используйте как единственное хранилище финансовых данных.

**FinTrack Mac** — русскоязычная модификация [Mint Leaf 4.2](https://github.com/Kolomaster68/mint-leaf) (© 2026 Joe Farmer; **MIT**). Исходная лицензия сохраняется в [`LICENSE`](LICENSE). Наши изменения не предназначены для обхода лицензии оригинального автора.

## Возможности

- Нативное приложение для **macOS 14+ / Mac Apple Silicon**, Swift + SwiftUI.
- Современный финансовый дашборд: баланс, активы, обязательства, денежные потоки, категории, счета, операции и ближайшие платежи.
- Русский каталог локализации (661 ключ, перевод ещё проходит аудит).
- Три валюты в списках выбора: **RUB, USD, EUR**; рубль по умолчанию.
- Пересчёт совокупных показателей по курсам ЦБ РФ с предупреждением о неактуальных курсах. Применение текущих курсов к историческим графикам даёт ориентировочную оценку, а не бухгалтерский курс конкретной даты.
- Отдельный идентификатор приложения `com.maxliv234.fintrackru`: исходный Mint Leaf и его локальная база остаются нетронутыми.

## Скачать приложение

Откройте **[Actions → FinTrack Mac — build and test](../../actions/workflows/build-fintrack-macos.yml)**, выберите успешный запуск и скачайте артефакт **FinTrack-Mac-Apple-Silicon**. В нём `.dmg` и `.zip`. Приложение сейчас не подписано Apple Developer ID и не нотарифицировано: macOS может показывать предупреждение безопасности. Не отключайте Gatekeeper глобально.

## Исходники и повторяемая сборка

Репозиторий содержит патч-скрипты и workflow, которые берут исходники [Mint Leaf `v4.2`](https://github.com/Kolomaster68/mint-leaf/tree/v4.2) (закреплён SHA `9731ed052196a9387527661530df791ef9011d8e`), применяют изменения и компилируют их в GitHub Actions. После **успешных тестов и сборки** Actions также закоммитит производный исходный Swift-проект в этот репозиторий, сохранив MIT-лицензию. Это даёт воспроизводимость и позволяет проверять полный diff.

Локальный запуск с Xcode 16+:

```bash
bash install_and_build.sh
```

Если Xcode на Mac не установлен, установщик только подготовит исходники в `~/Developer/FinTrack-Mac`; сборка выполняется GitHub Actions. Вход в приложение и реальная отправка финансовых данных в GitHub **не требуются**.

## Проверки

```bash
python3 -m unittest discover -s tests -v
bash tests/verify_cbr_parser.sh  # при наличии Swift-компилятора
```

CI дополнительно запускает XCTest, собирает приложение для arm64 и выпускает загружаемый `.dmg`.

## Ограничения текущей версии

- Полная русификация динамических сообщений ещё не гарантирована; `LOCALIZATION_REPORT_RU.md` появляется после применения патча.
- Если курс недоступен, применяются закешированные или резервные ставки — для точных расчётов их необходимо проверить.
- Существующие счета в других валютах не удаляются: их исторические данные сохраняются.
- Файлы банков, SwiftData, резервные копии, токены и персональные операции **никогда не коммитятся в репозиторий**.
