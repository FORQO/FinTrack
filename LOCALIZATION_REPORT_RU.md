# FinTrack Mac — проверка локализации

- Строк в каталоге: **661**.
- Статических строк интерфейса, которым ещё нужен перевод: **20**.
- Числа на новом экране переводятся в выбранную валюту через ExchangeRateService.
- Онлайн-курс не всегда доступен, поэтому данные с устаревшим курсом помечаются как оценочные.
- Остатки, существующие категории и исторические операции не меняются.
- Новый bundle ID изолирует данные оригинального Mint Leaf.
