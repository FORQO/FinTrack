# FinTrack Mac — проверка локализации

- Строк в каталоге: **681**.
- Статических строк интерфейса без записи в каталоге: **0** из последнего аудита.
- Технические обозначения валют (`$ USD`, `€ EUR`, `₽ RUB`) специально сохранены без изменения.
- Это проверка **статических литералов** SwiftUI, а не гарантия полного перевода динамических, вычисляемых и серверных сообщений.
- Новый финансовый экран считает суммы в выбранной валюте через ExchangeRateService.
- При недоступности актуального курса отображается предупреждение.
- Данные исходного Mint Leaf изолированы отдельным bundle ID.

## Следующие проверки

- Просмотр динамических уведомлений, сообщений импорта и финансовых прогнозов в русской локали.
- Проверка Xcode UI и доступности узкого окна.
- Проверка отображения российского числового формата и денежных округлений.

## Уточнение русской терминологии

- Термины `Merchant` и связанные подписи приведены к формулировкам про продавцов и варианты названий продавцов.
- Отдельной функции чековой книжки в интерфейсе нет. Необязательное поле номера чека остаётся только в SwiftData и старых резервных копиях; сохранено для совместимости с данными пользователей.
